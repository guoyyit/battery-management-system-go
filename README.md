# 本地电池管理系统（BMS, Go）

面向**可配置串数与容量**的多电芯串联电池组，提供荷电状态（SOC）估算、被动均衡、
动态电流限制、保护锁存、故障追溯与崩溃恢复。电池模型与电流/电压/温度输入全部由
本地确定性模拟器驱动，不依赖任何外部硬件或服务。

## 运行与测试

```bash
go build ./...
go test ./...          # 全部测试
go test -race ./...    # 并发竞态检测
go run .               # 冒烟示例
```

所有模拟均由 `Config.Seed` 决定，固定种子下结果可复现。

## 模块结构（`bms/` 包）

| 文件 | 职责 |
| --- | --- |
| `config.go` | 可配置参数、默认值、参数校验、温度降额曲线校验 |
| `models.go` | 采样帧、单体/电池组快照、故障类型与记录、OCV 表双向插值 |
| `simulator.go` | 本地模拟：真实 SOC 安时积分、内阻压降、均衡分流压降、热模型、电流噪声与漂移、短路注入 |
| `soc.go` | SOC 估算：安时积分 + 静置 OCV 校正 + 上电强制收敛 |
| `balancer.go` | 被动均衡决策、滞回去抖、均衡中有效电压补偿、累计均衡电量 |
| `current_limit.go` | 温度降额 + SOC/单体电压约束的动态充放电限流 |
| `protection.go` | 过压/欠压/过温/过流/短路判定、滞回、锁存与显式清除 |
| `faults.go` | 有序、可翻页的故障历史 |
| `store.go` | 单文件 JSON 原子持久化（临时文件 + fsync + rename） |
| `bms.go` | 编排核心：单锁串行化采样/均衡/保护/查询，定时与事件触发落盘 |

## SOC 估算模型

电流约定：**I > 0 为充电，I < 0 为放电**。

1. **安时积分（库仑计数）**：每个采样周期对每个单体
   `SOC += I·dt / (3600·CapacityAh)`，充电侧带固定库仑效率系数。
2. **静置 OCV 校正**：当 `|I| ≤ 0.05 A` 并持续 `RestForOCV`（默认 10 分钟）后，
   将各单体开路电压查 OCV 表得到目标 SOC，以增益 `OCVCorrectionGain`（默认 0.1）
   逐步靠拢，单次校正幅度受 `MaxOCVCorrectionV`（默认 0.30 V 等效 SOC）限幅，
   避免单帧噪声造成跳变。该机制持续修正电流噪声与缓慢漂移引入的积分误差，
   长时工况测试误差约 0.4%（< 5% 指标，见 `TestSOCLongRunAccuracyWithinFivePercent`）。
3. **上电/静置后重新上电收敛**：冷启动后若电池处于静置状态，执行一次无增益限幅的
   全量 OCV 校正（`ForceOCVCorrect`），不再信任陈旧积分值；崩溃恢复则以持久化的
   SOC 为准，避免重启瞬间被噪声覆盖。
4. **OCV 表**：`SOC ↔ 电压` 单调表，双向分段线性插值并在表端截断。

## 被动均衡

- 触发：任一单体电压相对最低单体超过 `BalanceDeltaV`（默认 30 mV），或 SOC 差超过
  `BalanceDeltaSOC`（默认 2%），即闭合该单体旁路开关。
- 释放滞回：运行中的开关需等差距缩小到触发阈值的一半才释放，防止阈值附近抖动。
- 均衡电流恒为 `MaxBalanceCurrentA`（默认 0.05C），从对应单体单独扣减电量。
- **均衡中采样有效性**：闭合分流电阻会使端电压读低 `I_balance·R_int`，系统在决策与
  保护前对该压降进行补偿（`EffectiveVoltages`），因此均衡进行中电压采样仍然有效。
- 开关状态与累计均衡电量（Ah）均可通过快照查询，并参与持久化。

## 动态电流限制

每周期独立计算充/放电上限（`CurrentLimiter.Apply`），取以下约束的最严值：

- **温度降额**：可配置的分段线性曲线（`ChargeDerating` / `DischargeDerating`），
  曲线外按端点截断；默认充电在 0 ℃ 及以下禁止（析锂安全语义），55 ℃ 降为 0。
- **SOC**：高 SOC（>90%）充电线性收尾，低 SOC（<10%）放电线性收尾。
- **单体电压**：最高单体接近过压阈值时禁止充电，最低单体接近欠压阈值时禁止放电。

请求电流超出上限时按上限执行，返回值携带受限原因（如 `temperature_derating`、
`charge_disabled_low_temperature`、`cell_over_voltage_derating`）。

## 保护与安全语义

覆盖五类故障：过压、欠压、过温、过流、短路。

- **滞回去抖**：每类故障在高阈值触发，只有回落到「阈值 − 滞回带」以下才解除条件，
  阈值附近波动不会反复动作。
- **短路持续时间**：电流达到 `ShortCircuitCurrent` 并持续 `ShortCircuitDuration`
  （默认 5 ms）才触发，单个噪声尖峰不动作；过流同样要求持续一个采样周期。
- **锁存**：任一故障触发后立即断开充放电回路并锁存；即使物理条件恢复，接触器仍保持
  断开，只有显式调用 `ClearFaults()` 且**所有故障条件均已安全**时才能恢复。
- **原子断流**：在同一周期内先做保护判定再做安时积分；一旦本周期触发故障，该帧电流
  被强制为零且不计量，对外快照不可能出现「已保护但电流仍在计量」的中间态。

## 故障可追溯

`FaultRecord` 记录时间、类型、动作（触发/条件解除/锁存复位）、相关单体编号、
当时电压、温度、电流、SOC 与说明。历史按单调 ID 时间有序，支持零基分页
（`FaultHistory(page, pageSize)`）。

## 并发一致性

`BMS` 使用一把 `sync.RWMutex` 保护所有子系统状态变更与对外快照：

- 采样、均衡决策、保护判定在 `Step` 内同一把写锁下原子完成；
- `Snapshot` / `FaultHistory` 等查询在读写锁下返回深拷贝，任何时刻对外状态自洽；
- `go test -race ./...` 下采样与查询并发测试通过。

## 崩溃恢复

- 持久化内容：每单体 SOC、模拟器真值 SOC 与温度、累计积分电量、各单体均衡开关与累计
  均衡电量、锁存标志、活跃故障集合、完整故障历史、下一个故障 ID。
- 写入方式：编码到临时文件 → `fsync` → 原子 `rename`，进程在任意时刻被杀死只会留下
  旧文件或新文件，不会出现半写损坏。
- 落盘时机：每秒定时落盘 + 每次故障/清除事件立即落盘；正常 `Stop()` 再落盘一次。
- 恢复语义：SOC、均衡进度与锁存状态不丢失；故障历史既不重复（恢复后对已锁存故障
  抑制重复「触发」记录）也不遗漏（完整记录随状态文件恢复）。

## 关键默认参数（通用锂离子单体，25 ℃）

| 参数 | 默认值 |
| --- | --- |
| 采样周期 | 100 ms |
| 过压 / 欠压阈值 | 4.20 V / 3.00 V |
| 电压滞回带 | 0.10 V |
| 过温阈值 / 滞回 | 60 ℃ / 5 ℃ |
| 充电 / 放电过流 | 2C / 3C |
| 短路电流 / 持续时间 | 6C / 5 ms |
| 均衡电压差 / SOC 差 / 电流 | 30 mV / 2% / 0.05C |
| 静置 OCV 判定时间 | 10 min |
| 单体模型 | 内阻 50 mΩ，3.00–4.20 V OCV 表，2.5 Ah |

所有参数均可通过 `Config` 字段或 `DefaultConfig(cellCount, capacityAh)` 调整，
`Config.Validate()` 会拒绝不自洽的配置。
